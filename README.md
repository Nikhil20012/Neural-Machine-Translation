# Neural Machine Translation: English to Hindi

A comparative study of two encoder-decoder architectures for English-to-Hindi translation, trained on the IIT Bombay parallel corpus. This project implements and evaluates a vanilla LSTM model against a GRU-based model with dot-product attention to understand how attention mechanisms affect translation quality, particularly on longer sentences.

## Key Findings

The attention-based model consistently outperforms the LSTM model on sentences longer than a few words. Without attention, the encoder must compress the entire source sentence into a single fixed-size vector, which loses information as sentence length grows. The attention mechanism lets the decoder selectively reference different parts of the source at each decoding step, producing more accurate translations for complex inputs.

Both models handle short, formulaic phrases well (single words like "method" or "value" translate perfectly), but the LSTM model's output degrades noticeably on longer inputs while the attention model remains coherent.

Detailed analysis and methodology are documented in `docs/NMT_Research_Paper.pdf`.

## Models

**LSTM Encoder-Decoder (no attention)**
- Embedding dim: 256, single LSTM layer for both encoder and decoder
- Encoder compresses source into final (h, c) states; decoder generates from that fixed context
- Trained 70 epochs with RMSprop on TPU
- Training accuracy reaches ~90%, but validation loss diverges after epoch 12 (overfitting)
- ~7.9M parameters

**GRU Encoder-Decoder with Dot-Product Attention**
- Embedding dim: 64, hidden units: 1024, single GRU layer for both encoder and decoder
- At each decoder step, computes attention over all encoder hidden states
- Trained 100 epochs with Adam (lr=0.006) on GPU
- Custom training loop with teacher forcing and masked loss
- Training loss drops from ~23 to ~1

## Dataset

[IIT Bombay English-Hindi Parallel Corpus](https://www.cfilt.iitb.ac.in/iitb_parallel)

The full corpus contains ~1M sentence pairs. Both models use a filtered subset of 25,000 pairs with sentence length caps (10 words for LSTM, 16 words for attention) to keep training feasible. Vocabulary is capped at 10,000 words for both languages.

## How to Run

Both notebooks are designed for Google Colab.

**LSTM model** (`Neural Machine Translation using LSTM.ipynb`)
- Requires TPU runtime for reasonable training speed
- Requires TensorFlow 2.6.0 and Keras 2.6
- Update all file paths (dataset root, model checkpoint, preprocessed data pickle) to match your Google Drive layout
- Download the IITB parallel corpus files (`IITB.en-hi.en` and `IITB.en-hi.hi`) and place them in your Drive

**Attention model** (`S2S-Attention.ipynb`)
- Requires GPU runtime
- Update the dataset path to point to `dataset_tdl.csv` (the merged dataset generated by the notebook)
- Run cells sequentially; the notebook handles dataset creation, training, and inference
